Bagaimana data menjadi dashboard?

Data warehousing menyatukan data yang terpisah agar bisa dianalisis bersama.

01

Mengumpulkan data

Tiga file Excel: IPM, lama sekolah, dan jumlah sekolah/guru/murid.

02

Menyamakan format

Bersihkan nama daerah dan angka. Cocokkan nama wilayah serta tahun integrasi.

03

Menyimpan bersama

DuckDB memakai dimensi wilayah, dimensi tahun, dan satu tabel fakta. Notebook juga memuat data ke DuckLake.

04

Menyajikan hasil

Dashboard web membaca snapshot CSV terintegrasi. Streamlit menyediakan opsi koneksi MotherDuck.

Satu baris data mewakili satu wilayah dalam satu tahun. Memilih Kota adalah contoh slice. Memilih Kota dengan IPM tertentu adalah dice. Menggabungkan jumlah murid semua wilayah adalah agregasi.
Status implementasi

Integrasi diperiksa CSV cocok dengan tiga Excel, memiliki 38 baris dan tidak memiliki nilai kosong atau duplikat.

Versi web Penghitungan ulang indikator dilakukan di browser dari snapshot CSV, tanpa koneksi database langsung.

MotherDuck Aplikasi Python menyiapkan koneksi. Tahap publikasi MotherDuck dalam notebook masih kosong dan belum diverifikasi.

Jenjang SD/SMP/SMA disimpan sebagai kolom, bukan dimensi tersendiri. Data hanya mencakup satu tahun sehingga belum menyediakan drill-down waktu atau tren tahunan.

Sumber dan batas pembacaan hasil
  • IPM: IPM 2025.xlsx, sheet IPM Jawa Timur. Nilai tampil sesuai lampiran pengguna.
  • Lama sekolah: rataratalamasekolah.xlsx, Sheet1. Header menyebut usia 15 tahun ke atas. Angka agregat Jawa Timur pada file adalah 8,81 tahun.
  • Sekolah/guru/murid: dataset_integrasi_sekolah_guru_murid_jawa_timur.xlsx, tiga sheet SD/SMP/SMA. Tahun 2025 ditambahkan oleh notebook. Tahun sumber dan cakupan sekolah perlu dilengkapi.
  • Rata-rata IPM dan lama sekolah di dashboard adalah rata-rata sederhana antardaerah, bukan angka resmi agregat provinsi.
  • Rasio murid per guru adalah total murid dibagi total guru. Rasio ini bukan ukuran jumlah murid di setiap kelas atau kualitas mengajar.
  • Data belum memuat SMK, madrasah, status negeri/swasta, atau alamat sekolah secara terpisah. Cakupan sebenarnya harus dipastikan dari sumber.
  • Jumlah murid SD dan SMA tidak dapat langsung dipakai untuk menghitung angka putus sekolah atau transisi kohort.
Rujukan metode dan publikasi web
  • BPS: metode baru IPM menjelaskan dimensi kesehatan, pendidikan, dan standar hidup. RLS komponen IPM menggunakan usia 25 tahun ke atas.
  • GitHub: pengaturan publikasi GitHub Pages.
  • Streamlit: deployment dari repository GitHub.

Rujukan ini mendukung definisi dan cara publikasi. URL tabel asli masing-masing dataset belum tersedia pada lampiran.
